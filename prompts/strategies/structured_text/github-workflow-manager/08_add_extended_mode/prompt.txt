Context:
System should optionally integrate with GitHub.

Requirements:

Must Have:
- Add mode: `github_fetch_mode`
- Fetch workflow runs via GitHub REST API (using `requests`) or `gh` CLI
- Convert fetched data into domain model
- Resolve the PAT in this priority order:
  1. `GITHUB_TOKEN` environment variable
  2. `secrets/.env` file in the project root
  3. Prompt user to input PAT securely if neither is found
- Do not persist a user-entered PAT unless explicitly configured
- Add a `fetch --owner <owner> --repo <repo>` CLI subcommand that triggers a GitHub fetch and stores the results locally
- Add a "Fetch from GitHub" option to the interactive menu (`python -m src`) that prompts for owner/repo and fetches runs

Should Have:
- Handle API errors gracefully (rate limits, invalid token, network issues)
- Validate token before making requests

Could Have:
- Incremental fetch (only runs newer than the latest stored run)

Won't Have:
- Implement full authentication management (OAuth flows, token refresh)
