Context:
Multiple attempts per workflow run are not modeled.

Requirements:

Must Have:
- Create class `WorkflowRunAttempt`
- Attributes:
  - `id: int`
  - `run_id: int`
  - `attempt_number: int`
  - `status: str`
  - `conclusion: Optional[str]`
  - `created_at: datetime` (CEST, UTC+2)
- Establish relationship to `WorkflowRun`
Should Have:
- Support serialization/deserialization

Could Have:
- `duration_seconds: float` to track attempt-specific execution time

Won’t Have:
- Optimize persistence or storage performance
