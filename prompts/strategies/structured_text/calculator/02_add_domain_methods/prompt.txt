## Task: Add additional mathematical operations

### Must
- Implement the following operations:
  - square (x^2)
  - sqrt(x)
  - power(x, y)
  - modulo(x, y)
- Each operation must follow the existing operation interface
- Results must be correct for valid numeric inputs

### Must
- Handle edge cases:
  - sqrt of negative numbers must raise an error or return a defined error result
  - modulo by zero must raise an error
  - power with negative or fractional exponents must produce correct results
- All new functionality must be accessible via `python -m src` — both as an interactive menu option and as a one-shot CLI flag.


### Could
- Support operator aliases (e.g., ‘^’ for power)
- Reuse shared computation logic

### Won’t
- Introduce duplicate operations (e.g., a second add implementation)
- Deviate from existing operation naming or interface conventions
