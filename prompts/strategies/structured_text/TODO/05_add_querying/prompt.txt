## Task: Add due date and overdue filtering to task queries

### Must
- Extend the existing task query interface with the following new filters:
  - By due date range (tasks due before or after a given datetime; e.g. "due this week")
  - By overdue status (due_date is set and earlier than the current CEST time)
- Return filtered collections consistent with the existing `list_tasks` return format
- Overdue detection must use current CEST time (UTC+2)
- All new functionality must be accessible via `python -m src` — both as an interactive menu option and as a one-shot CLI flag.

### Should
- Support combining the new filters with the existing status filter in a single call
- Preserve existing `list_tasks(status=...)` behavior unchanged

### Could
- Add text search by partial match on task title or description

### Won't
- Reimplement or replace the existing status filtering already present in `TodoService`
- Use a database query engine or external index
