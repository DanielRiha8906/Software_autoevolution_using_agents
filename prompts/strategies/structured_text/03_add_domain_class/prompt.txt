## Task: Introduce MemoryEntry domain class

### Must
- Create a MemoryEntry domain class representing one stored calculation attempt.
- Store operation name, input operands, result, success/error state, execution timestamp, and execution_time_ms.
- Support both successful and failed calculations.
- Provide serialization and deserialization to/from JSON-compatible dictionaries.

### Should
- Preserve compatibility with existing calculation history where reasonable.
- Use clear field names that support later querying and reporting.

### Could
- Add a unique identifier for each memory entry.

### Won’t
- Store calculation history only as formatted strings.
- Mix display formatting with stored data.
